Kebijakan Privasi NoteKu By Yordan

Terakhir diperbarui: 11 November 2026

NoteKu By Yordan adalah aplikasi catatan. Halaman ini menjelaskan data apa yang dipakai aplikasi dan ke mana data itu pergi.

Data yang disimpan

Catatan, kategori, tugas, ikon kalender, dan nama profil disimpan di browser perangkatmu. Foto profil, memo suara, dan PIN tidak dikirim ke mana pun dan hanya ada di perangkat ini.

Login dengan Google (opsional)

Jika kamu memilih masuk dengan Google, aplikasi meminta dua izin:

  • Alamat email: hanya untuk menampilkan akun mana yang sedang masuk.
  • Data aplikasi di Google Drive (drive.appdata): aplikasi membuat satu file cadangan di folder tersembunyi khusus NoteKu di Google Drive-mu. Aplikasi tidak bisa membaca atau mengubah file Drive lain milikmu.

Catatanmu dikirim langsung dari perangkatmu ke Google Drive-mu. Pemilik aplikasi tidak memiliki server atau database untuk catatanmu dan tidak dapat melihat isinya.

Yang tidak kami lakukan

  • Tidak menjual atau membagikan datamu kepada pihak lain.
  • Tidak memakai iklan atau pelacak.
  • Tidak menyimpan datamu di server milik pemilik aplikasi.

Mengontrol dan menghapus data

  • Ketuk Keluar di Pengaturan untuk berhenti sinkron di perangkat itu.
  • Cabut akses kapan saja di myaccount.google.com/permissions. Di sana kamu juga bisa menghapus data aplikasi NoteKu dari Drive.
  • Ketuk Hapus semua data di Pengaturan untuk menghapus catatan di perangkat.

Penggunaan data Google

Penggunaan informasi yang diterima dari API Google mengikuti Kebijakan Data Pengguna Layanan API Google, termasuk persyaratan Penggunaan Terbatas.
